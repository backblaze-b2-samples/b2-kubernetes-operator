# Roadmap

| Milestone | Scope |
| --- | --- |
| v1alpha1 (this release) | ClusterProviderConfig, B2AccessPolicy, Bucket (type, info, lifecycle, CORS, SSE-B2 by default, Object Lock, Cloud Replication), ApplicationKey (scoping, expiry, rotation, zero-downtime replacement), B2Account (Partner API) |
| Next | Delivering Secrets into remote (customer) clusters from a central operator; event notification rules; bucket access logging; policy status |
| Later | COSI driver built on the same client; OLM bundle and OperatorHub listing |
| v1 | API freeze with a conversion webhook, documented support policy |

Open questions are tracked as GitHub issues.

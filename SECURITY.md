# Security policy

Please do not report security vulnerabilities through public GitHub issues.

Report them privately through [GitHub security advisories](https://github.com/backblaze-b2-samples/b2-kubernetes-operator/security/advisories/new) for this repository.

Include the affected version, a description of the issue, and steps to reproduce it. We will acknowledge your report and keep you informed as we investigate.

The design and threat model are described in [docs/security.md](docs/security.md).
